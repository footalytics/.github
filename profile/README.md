# Footalytics – AI football predictions you can chat with

**Footalytics** is an AI chat assistant for football (soccer) match predictions and previews, made by [Farvor](https://farvor.com). Ask about any upcoming match in plain English or Chinese and get a clear, sourced match preview with win/draw/loss probabilities, and check every past forecast on a public accuracy page.

👉 **Try it free (limited-time beta): [footalytics.farvor.com](https://footalytics.farvor.com)**

[Website](https://footalytics.farvor.com) · [Accuracy tracking](https://footalytics.farvor.com/accuracy) · [Methodology](https://footalytics.farvor.com/methodology) · [Leagues](https://footalytics.farvor.com/leagues) · [中文](https://footalytics.farvor.com/?lang=zh)

## What you can ask

- *"Who wins Arsenal vs Chelsea this weekend?"*
- *"Preview Real Madrid's next Champions League match"*
- *"曼城下一场英超比赛胜率是多少？"*

## Features

- 🤖 **AI chat predictions** – ask in natural language, get an answer in seconds
- ⚽ **Match previews** – win / draw / loss probabilities, expected goals and likely scorelines
- 📈 **Team form** – recent results and ratings built from real match data
- 🆚 **Head-to-head** – how the two teams have fared against each other
- 🩹 **Injuries and team news** – gathered from public sources, with sources credited
- ✅ **Accuracy tracking** – every forecast is logged before kick-off and graded afterwards, misses included ([see the record](https://footalytics.farvor.com/accuracy))
- 📖 **Open methodology** – how the probabilities are produced ([read it](https://footalytics.farvor.com/methodology))
